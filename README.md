# True Insight

> A complementary holistic practice for integrative medicine

## About Us

**True Insight** is a practice where we help you uncover the root causes of your complaints and activate your own self-healing ability. We believe in a holistic approach to health and wellbeing.

### Our Approach

- **Holistic** - We look at the complete picture of your health
- **Investigative** - We help you discover the real causes
- **Empowerment** - We activate your own self-healing ability
- **Complementary** - We work alongside existing healthcare

## Features

- Information about our practice
- Contact and appointments
- Blog with health advice
- Frequently asked questions

## Technology

This project is built with:
- **Vue 3** - Progressive JavaScript framework
- **Vite** - Fast build tool
- **CSS3** - Modern styling

## Getting Started

1. Clone this repository
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`
4. Build for production: `npm run build`
